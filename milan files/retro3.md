Wat hebben we gedaan

We hebben de quests in databestanden per regio gezet. Een script leest die bestanden en bouwt de lijst met filterknoppen zelf op. Een echte API heeft een server nodig, dus we hebben bestanden gekozen die je ook kunt gebruiken als je de pagina’s gewoon opent. Hierdoor is de code overzichtelijker en voeg je een quest toe met één regel. Daarna hebben we de pagina van Fontaine gemaakt met quests, verzamelobjecten, personages, winkels en lore. Als laatste hebben we de pagina van de Temple of Space gemaakt.
