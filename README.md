### projectgegevens:

Het project dat ik dit keer wil maken is een wiki over genshin impact en de wereld van teyvat. Ik vind de wereld, de personages en de verhalen erg interessant, en met dit project wil ik alles overzichtelijk verzamelen op één plek. Ik gebruik HTML voor de structuur, CSS voor de opmaak en JavaScript voor de interactiviteit, zoals zoeken en filteren.



Als ik het openbaar zet, gelden er een paar randvoorwaarden. De AVG is niet van toepassing, want er worden geen persoonsgegevens gebruikt of opgeslagen. Copyright is wel relevant, maar op twee manieren: mijn eigen teksten en code zijn mijn werk, ik zet mijn naam erachter en ik wil niet dat ze zomaar volledig gekopieerd worden. Afbeeldingen, muziek, namen en andere content uit het spel zijn echter eigendom van HoYoverse, dus die kan ik niet zomaar gebruiken. Ik moet mijn eigen teksten schrijven, duidelijk vermelden dat het een fanproject is en geen officiële website, en voorzichtig zijn met het overnemen van officiële afbeeldingen.

ik wil dit project beginnen op de datum 29/9/2026 en ik neem aan dat ik hem 16/9/2026 klaar heb.
